## ⚡ Key Features

* **Trading Philosophy:** Core principles focused on Liquidity, Price Action, Execution, and Discipline.
* **Verified Trading Journal:** Clean tabular view of historical setups with detailed modal breakdowns (Risk/Reward, P&L, Execution Thesis).
* **Performance Dashboard:** Real-time metrics including Win Rate, Avg R:R, Profit Factor, and an interactive Chart.js Equity Curve.
* **Market Terminal Focus:** Dedicated breakdown for **XAUUSD**, **BTCUSD**, and **Forex Majors**.
* **Modern Dark UI:** Lightweight glassmorphism, responsive mobile-first architecture, and terminal-inspired design.
